# ToolPocket · 工具袋

> 37 个在浏览器里跑完的在线小工具 —— 不用注册，文件也不上传。

**在线使用：<https://tools.maomaowang.top/>**

---

## 这是什么

一套在浏览器里**本地完成计算**的在线工具站。压图、转格式、格式化 JSON、算哈希、生成密码、
换算单位、解析 cron……一共 37 个，中 / 英 / 日三种语言各一套页面。

它最大的特点不是"功能多"，而是**没有服务端**：所有处理都在访问者的浏览器里完成，
文件从头到尾没有离开过用户的设备。因此也就不存在"注册才能用""今天只剩 3 次"
"下载要开会员"这些常见的限制。

## 特点

- **文件不上传** —— 图片、文本、密码都在本机浏览器里处理，服务端不参与
- **不用注册登录** —— 打开即用，没有账号体系
- **没有次数限制与水印** —— 因为不消耗服务器资源，也就没有限流的理由
- **零外部请求** —— 不引字体、不引 CDN、不引统计脚本；整站只有自己的 HTML / CSS / JS
- **三语独立页面** —— 中文 / English / 日本語 各自一个网址，便于搜索收录
- **可装成桌面应用** —— 带 PWA 支持，装好后是一个独立窗口，**断网也能继续用**
- **响应式** —— 手机与桌面分别适配，不是"桌面版缩小"

## 技术实现

- **原生 HTML + CSS + JavaScript**，没有框架、没有运行时依赖，也不需要联网加载任何资源
- **数据驱动的构建**：`src/tools.json` 是全站唯一的工具注册表，
  `src/build.mjs` 依据它 + 三语文案生成全部页面、manifest 与 sitemap
- **服务端职责为零**：静态托管即可，所有逻辑都在访问者的浏览器里
- **本机可验证**：两个测试脚本都不依赖浏览器环境

```bash
node src/build.mjs      # 生成三语页面（约 88 个文件）
node test/check.mjs     # 契约检查：DOM / 文案 / 资源引用 / manifest / 移动端 / 页面结构
node test/runtime.mjs   # 在 Node 里真跑一遍工具脚本，断言输出结果
```

## 目录结构

```
assets/          样式与前端脚本（全站共用一份 CSS）
  tools/         37 个工具各自的实现
src/
  build.mjs      静态站生成器（读数据 → 出页面）
  tools.json     工具注册表（全站唯一数据源）
  i18n/          三语文案
  make-icons.mjs 图标生成（手写 PNG 编码，无第三方依赖）
test/            上线前的自动检查
tools/           生成出来的工具页（构建产物）
```
