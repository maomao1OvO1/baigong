    よくある質問

    Base64 にするとファイルが大きくなるのはなぜ？

    3 バイトが 4 文字になるからです。ちょうど +33% で、さらに data: 接頭辞のぶんが加わります。これは小さな話ではありません。200 KB の写真を HTML や CSS に埋め込むと約 267 KB のテキストが増え、しかもそのテキストは**個別にキャッシュできず、CDN も使えません**。

    どういう時に埋め込む価値がありますか？

    小さな素材です。アイコン、スプライト、10 KB 以内のロゴなど。ネットワークの往復が 1 回減るのは低速回線では確かな利点ですが、ファイルが大きいと逆転します。ブラウザはそのテキストを読み終えるまで、それを使う要素を描画できません。

    画像はどこかに送信されますか？

    いいえ。ブラウザ標準の FileReader で読むだけで、端末内に留まります。ここでは特に重要です。変換する画像は私的なものが多く、オンラインの変換サービスは定義上それを送信します。
