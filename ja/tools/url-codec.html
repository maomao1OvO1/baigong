URL のエンコードとデコード

URL とクエリ文字列のパーセントエンコード／デコード。「URL 全体を変換」と「値だけを変換」を分けています。コールバック URL が動かなくなる原因は、たいていこの混同です。

よくある質問

2 つのスコープの違いは？

単一の値（コンポーネント）は / : ? & = # もエスケープします。クエリ文字列の中に入れる値はこちら。URL 全体はこれらの構造文字を保ちます。

エンコードしたリンクが動かなくなりました

ほぼこれが原因です：URL 全体を「単一の値」としてエンコードすると、/ と ? が %2F と %3F になり、サーバーには 1 つの長いファイル名として見えます。

サーバーに送信されますか？

いいえ。ブラウザ内の文字列処理だけです。
