CSV ⇄ JSON 変換

CSV と JSON の相互変換。単純なツールが壊れる 3 つのケース——引用符内のカンマ、セル内の改行、二重引用符によるエスケープ——に対応します。Excel の書き出しには概ね 3 つとも含まれます。

よくある質問

カンマで分割するだけではだめな理由は？

実際の CSV には、引用符内のカンマ、セル内の改行（Excel のメモ列など）、二重引用符によるエスケープが含まれます。文字単位で解析するのが唯一正しい方法です。

数値や true/false は変換されますか？

はい。数値やブール値に見える値は JSON の数値・ブール値になります。007 のような値は文字列として保持されます。

JSON がネストしている場合は？

トップレベルの配列要素が 1 行になります。キーは全オブジェクトの和集合で、ネストしたオブジェクトは JSON 文字列としてセルに入ります。
