よくある質問

CSS は読み込まれているのに反映されません。MIME が原因ですか？

その可能性が高いです。スタイルシートが text/plain で返されると、ブラウザは適用を**拒否**します。コンソールには MIME type mismatch としか出ません。JavaScript も同じです。静的サイトで「ファイルはあるのに反応しない」最常见の原因です。

1 つの MIME に複数の拡張子がある場合、どれを使うべき？

サーバーにとっては同じです（見るのは型だけ）。違いが出るのは人とツールに対してです。.jpeg と .jpg は同じ画像、.mjs は Node に「ES モジュール」と伝えるために存在します。

拡張子や MIME でのアップロード検証は安全ですか？

安全ではありません。どちらもクライアントが送る値で、名前を変えれば回避できます。スクリプトを photo.png、型を image/png と偽れば、拡張子だけの検証は素通りします。サーバーは実際のバイト列（magic bytes）を確認し、できれば保存前に再エンコードすべきです。
