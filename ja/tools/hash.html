ハッシュ生成（MD5 / SHA-1 / SHA-256 / SHA-512）

MD5・SHA-1・SHA-256・SHA-512 をまとめて計算し、hex と Base64 の両方を表示します。ブラウザが MD5 を提供しなくなったため、ここでは自前で実装しています。

すべてブラウザ内で処理。送信も保存もしていません。

MD5 と SHA-1 はチェックサム専用です。パスワードや署名には使わないでください。

よくある質問

MD5 はまだ使えますか？

用途次第です。署名やパスワード保存には使えません（MD5 と SHA-1 の衝突は現実に構成されています）。単純なチェックサムとしては今も十分使えます。

計算結果が他サイトと違うのはなぜ？

多くは末尾の空白や改行が原因です。ハッシュはバイト単位で厳密なので、改行が 1 つ増えるだけで値が変わります。

ファイルのハッシュは計算できますか？

このページはテキスト用です。ファイルは md5sum / certutil -hashfile などのコマンドをご利用ください。
