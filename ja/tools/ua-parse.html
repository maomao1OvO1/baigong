User-Agent 解析

サーバーログやバグ報告は 120 文字の User-Agent であふれています。貼り付ければ、ブラウザ・エンジン・OS・端末種別が言葉で出ます。
あなた自身の User-Agent は既に入っています。そしてどこにも送信しません。

よくある質問

Safari と書いてあるのに Chrome と判定されるのはなぜ？

Chrome 系の文字列はすべて AppleWebKit と Safari/537.36 を含むからです。文字列の前半に Safari があるからといって、それがブラウザとは限りません。Edge・Opera・Samsung Internet の文字列にも Chrome/ が入るため、これらを先に判定する必要があります。本ツールはその順序で処理しており、手書きの解析器が最も間違えやすい箇所です。

User-Agent で機能の出し分けをしてもよい？

年々難しくなっています。Chrome はマイナーバージョンを固定し、Safari は幅広いリリースを 16.0 と報告し、Chromium 系は UA-CH（Sec-CH-UA ヘッダー群）へ移行中です。統計や調査の手がかりとして使うのは構いませんが、セキュリティ判断には使えません。クライアントは自由に書けます。

Windows 10 / 11 と出ました。どちらですか？

User-Agent からは判別できません。どちらも Windows NT 10.0 を報告し、マイクロソフトもそのままにすると表明しています。この文字列だけで区別できると主張するものは推測です。
