よくある質問

? が付いた省略可能なフィールドはどこから来ますか？

あなたのデータからです。配列に複数のオブジェクトが入っていて、あるキーが一部にしか無い場合、そのキーは省略可能として扱われます。これが実際の API の姿です。スイッチを切れば、すべて必須として出力します。

同じフィールドが、ある要素では文字列、別の要素では数値のときは？

ユニオン型 string | number になります。これは意図した動作です。any に潰すと、型を使う場所へエラーを先送りするだけだからです。

空の配列が unknown[] になるのはなぜ？

空の配列には要素の情報が何もないため、正直に推論できる答えがありません。unknown[] は中身を書くよう促し、any[] は何でも黙って通してしまいます。
