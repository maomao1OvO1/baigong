よくある質問

コードではどの規則を使うべき？

言語の慣習に従ってください。JavaScript / Java の変数は camelCase、Python / Rust は snake_case、型やクラスは PascalCase、モジュール定数は CONSTANT_CASE が一般的です。同じファイル内で統一することが最も重要です。

日本語や中国語はどうなりますか？

CJK には大文字小文字がないため、そのまま保持されます。camelCase はラテン文字向けの規則なので、これは正常な動作です。

複数行に対応していますか？

はい。空行以外の各行を個別に変換します。列名の一覧を貼り付けて一括変換するのに便利です。
