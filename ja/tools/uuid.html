UUID / ULID / NanoID 生成

UUID v4、時刻順に並ぶ UUID v7、ULID、NanoID を最大 100 個まで生成します。乱数は Math.random ではなく、ブラウザの暗号学的乱数から取得します。

すべてブラウザ内で処理。送信も保存もしていません。

UUID v7 と ULID は時刻順に並びます。UUID v4 は完全ランダム、NanoID は最短です。

よくある質問

UUID v4 と v7、どちらを使うべき？

新規プロジェクトなら v7 をおすすめします。先頭がミリ秒タイムスタンプなので生成順に並び、データベースのインデックスが断片化しません。v4 は完全ランダムで識別子としては十分ですが、大量のランダム挿入は B-tree インデックスを劣化させます。

ULID と UUID v7 は似ていますが？

どちらも時刻順に並びます。ULID は Crockford Base32 の 26 文字（ハイフンなし・短く URL 向き）、UUID v7 は標準の 36 文字形式で、多くのデータベースがネイティブ型を持っています。

これらの ID を秘密情報に使えますか？

乱数強度は十分ですが、ID はパスワードではありません。保存やログ出力が前提の値です。トークンには専用の生成器をお使いください。
