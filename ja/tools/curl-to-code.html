curl → コード

ブラウザの「Copy as cURL」でコピーしたリクエストを、コードにしたい。貼り付ければ JavaScript の fetch、axios、Python の requests の形で出ます。ヘッダーは 1 つも落としません。
ヘッダーの取りこぼしは定番のバグです。Content-Type が消えると、サーバーは JSON をフォームとして解釈し、自分のミスに見えるエラーを返してきます。内容はブラウザの外に出ません。

すべてブラウザ内で処理。送信も保存もしていません。

よくある質問

body がファイルにあるので変換できない、と言われたのはなぜ？

そのコマンドが `-d @data.json` だからです。body は実行時にファイルから読まれるもので、ファイル自体はコマンドに含まれていません。空の body で変換して、成功するはずのないリクエストを調査させるより、データを直接書くよう伝えるほうが親切だと判断しました。

-L、-k、--compressed はどこへ？

curl 自身の動作にあたるもので、対応するコードがないため意図的に落としています。fetch と axios は元からリダイレクトを追い、自動で展開します。また `-k`（証明書検証のスキップ）は本番コードに持ち込むべきものではありません。

逆に、コードから curl へ変換できますか？

できません。1 つのコードは複数の curl コマンドに対応し、逆向きには唯一の正解がありません。curl からコードへは一意に決まるので、本ツールはその方向だけを扱います。
