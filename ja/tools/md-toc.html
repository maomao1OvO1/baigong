Markdown 目次生成ツール

目次の実体はリンクの一覧で、難しいのはアンカーです。GitHub は見出しを小文字にし、約物を落とし、空白を 1 つずつハイフンに変え、重複には -1 を付けます。手で書くと半分のリンクが黙って反応しません。
Markdown を貼り付けてください。コードブロックは飛ばすので、シェルのコメントが目次に入ることはありません。

すべてブラウザ内で処理。送信も保存もしていません。

よくある質問

目次をクリックしても反応しないのはなぜ？

ほぼ次の 3 つのどれかです。GitHub が落とす約物がアンカーに残っている、GitHub が小文字にする大文字が残っている、あるいは前の同名見出しと衝突している（衝突時 GitHub は 2 つ目を name-1 に向けます）。本ツールはこの 3 つすべてを GitHub の規則どおりに処理します。

日本語や中国語の見出しでも動きますか？

動きます。GitHub のアンカーは CJK 文字をそのまま残し、小文字化と約物の除去だけを行うので、「日本語の見出し」のアンカーは #日本語の見出し になります。本ツールが音訳や転写をしないのはそのためです。

同じ Markdown は GitLab や Notion でも使えますか？

必ずしも使えません。各サービスのアンカー規則は異なり、GitLab は特に差が大きいです。本ツールは最も一般的な GitHub に合わせています。他の場所で反応しない場合は、そのサービスの規則によるもので、ここが間違っているわけではありません。
