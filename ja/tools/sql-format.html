SQL フォーマッター

ログや ORM から出てくる SQL はたいてい 1 行です。貼り付ければ、句ごとに改行し、条件をインデントし、キーワードを大文字にした形になります。
先に字句解析を行うため、文字列リテラルの中身が書き換わることはありません。

すべてブラウザ内で処理。送信も保存もしていません。

よくある質問

文字列の中のテキストは変更されますか？

されません。そこが「先に解析する」理由です。name = 'select * from users' のような条件のうち、内側の文字は SQL ではなく**データ**です。単純な置換でキーワードを大文字にすると、保存された値まで書き換わり、クエリの挙動が静かに変わります。本ツールはトークンに分けてから判断します。

どのデータベース方言に対応していますか？

方言による解析は行わず、トークンの種類で整形します。そのため PostgreSQL、MySQL、SQLite、SQL Server、BigQuery のいずれでも使えます。代わりに、本当の構文エラーは指摘できません。`--` と `#` の行コメント、ブロックコメント、`''` のエスケープ、バッククォートと角括弧の引用符に対応しています。

テーブル名や列名が大文字にならないのはなぜ？

大文字にすると意味が変わるからです。PostgreSQL では引用符なしの識別子は小文字に畳まれ、大文字小文字を区別する照合順序では参照先のテーブルが変わります。本ツールはキーワードだけを大文字にし、識別子はそのまま残します。
