JSON パスで値を取り出す

API のレスポンスが何百行もあって、見たいのは 1 つのフィールドだけ。JSON を貼り、data.items[0].title のようなパスを書けばその値だけを取り出せます。a.b・a[0]・a[-1]・a[*].b に対応。データはブラウザから出ません。

すべてブラウザ内で処理。送信も保存もしていません。

よくある質問

キー名にドットが含まれる場合は？

引用符で囲みます：a["weird.key"]。忘れやすいポイントです。

完全な JSONPath ですか？

いいえ。日常的に使うのは「このフィールドを取りたい」「配列の 3 番目が欲しい」程度なので、記法は絞ってあります。
