よくある質問

4xx と 5xx の違いは？

4xx はリクエスト側の問題（パラメータ誤り、未ログイン、回数超過）、5xx はサーバー側の問題（クラッシュ、過負荷、上流のタイムアウト）です。コードを直すべきか容量を増やすべきかの判断基準になります。

418・499・599 が非公式とあるのは？

RFC に定義がありません。418 はエイプリルフールの遊び、499 は Nginx 独自、599 はプロキシで見られます。
