JWT デコーダー

JWT は JSON（ヘッダー＋ペイロード＋署名）の塊です。ここで中身を読み取れば、他人の解析ダッシュボードに貼る必要はありません。デコードはこのページ内で完結します。なお、デコードは検証ではないため、署名の確認はサーバー側で行ってください。

よくある質問

デコードできれば有効なトークンですか？

いいえ。ペイロードは誰でも自由に作れます。発行者を証明できるのは署名だけです。本ページは形式のデコードとクレームの表示のみを行います。署名検証はサーバー側で行ってください。

形式エラーになるのはなぜ？

JWT はドットで区切られた 3 つの部分から成ります。貼り付け時に最後の部分が欠ける、引用符付きの JSON 文字列のまま貼る、URL エンコードされたまま貼る、といった原因が一般的です。

本番のトークンを貼っても安全ですか？

送信は一切行いませんが、トークンはパスワード同等の機密です。テスト用トークンを推奨します。本番のものを使った場合は、後で失効・ローテーションしてください。
