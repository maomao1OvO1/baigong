HTML エンティティのエンコード / デコード

HTML をエスケープして文字として表示させたり、中 のような実体参照を元に戻したりできます。ASCII のみを要求する古いメールテンプレートや API にも。

すべてブラウザ内で処理。送信も保存もしていません。

エンコードは特殊文字を実体参照に、デコードは実体参照を元の文字に戻します。 既定はオフです。すべての漢字を &#xNNNN; にすると出力が数倍長くなります。

よくある質問

引用符もエスケープが必要ですか？

テキストノードでは & と < だけで十分ですが、二重引用符で囲んだ属性値では " も必要です。本ツールは 5 文字をまとめて変換するため、どの場面でも安全です。

日本語をエンティティに変換すべきですか？

下流が純粋な ASCII を要求する場合のみです。それ以外ではサイズが数倍になり、ソースも読めなくなります。そのため既定ではオフの独立スイッチにしています。
