カラー変換 — HEX / RGB / HSL

手元にある形式をそのまま貼ってください。形式は自動判別し、残り 2 つを表示します。「入力形式を選択」といった手順は不要です。

すべてブラウザ内で処理されます。送信も保存もしていません。

ここで色を選ぶと、上の入力欄に自動で入ります。

よくある質問

どの形式に対応していますか？

#abc、#aabbcc、rgb(r,g,b)、rgba(...)、hsl(h,s%,l%)。スペースの有無は問いません。

値は正確ですか？

RGB ↔ HEX は正確です。HSL は読みやすさのため丸めていますが、計算は標準的な CSS の式に従っています。

カラーピッカーはありますか？

入力欄の下にあります。ただし多くの方は既にコピーした色値を持っているため、貼り付けが最短です。
