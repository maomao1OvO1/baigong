文字列のエスケープ / 解除

同じ文字列でも、置く場所によって正しい書き方は異なります。JSON では生の改行や未エスケープの引用符が使えず、SQL では単引用符を 2 つ重ねる（バックスラッシュではない）必要があり、正規表現では多くの記号をエスケープします。ここでは一度に正しく変換でき、逆方向にも戻せます。

すべてブラウザ内で処理。送信も保存もしていません。

よくある質問

エスケープすれば SQL は安全ですか？

いいえ。これは文字列リテラルの書き方の話で、インジェクション対策ではありません。対策にはプレースホルダ（パラメータ化クエリ）を使ってください。

どちら向きに使えばいいですか？

対象の形式と、エスケープか解除かを選びます。「入れ替え」ボタンで文字列と方向が同時に反転し、往復確認ができます。
