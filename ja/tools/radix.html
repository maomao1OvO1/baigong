基数変換（2 / 8 / 10 / 16 / 36）

数値を入力すると、各基数での表記と、必要なビット数・バイト数が一度に表示されます。長い値は BigInt で扱うため、18 桁の ID が丸められることはありません。

すべてブラウザ内で処理されます。送信も保存もしていません。

「自動」は接頭辞や使用文字から判定します。 区切るとフラグやマスクの値が読みやすくなります。

よくある質問

電卓と結果が違うのはなぜ？

多くの電卓や JavaScript の数値は倍精度浮動小数点で、正確に表せるのは 2 の 53 乗までです。このページは BigInt を使うため、20 桁の ID やパーミッションマスクも正確に扱えます。

「自動」は何で判定しますか？

0x / 0b / 0o の接頭辞があればそれぞれ 16 / 2 / 8 進数、なければ a〜f を含む場合は 16 進数、それ以外は 10 進数として扱います。

グループ化したビット表示の用途は？

フラグやマスクの確認用です。4 ビットごとに区切ると 16 進数の 1 桁に対応し、8 ビットごとに区切るとメモリ上のバイト配置に対応します。
