JSON の整形と検証

JSON の整形・圧縮・検証。壊れている場合はエラー行を示します。API のレスポンスを確認する場面で便利です——そしてそれは、見知らぬサイトに貼るべきではない類のテキストでもあります。

すべてブラウザ内で処理。送信も保存もしていません。

整形は読みやすくインデントを付け、圧縮は空白をすべて除去して転送向けにします。

よくある質問

不正な JSON だとどうなりますか？

エラー内容と、可能であれば該当の行・列を表示します。推測せずに修正できます。

サイズの上限はありますか？

実質的な上限はありません。お使いの端末で処理するため、端末の性能次第です。

入力したデータは送信されますか？

いいえ。API キーや顧客データを含む JSON を扱うときにも安心です。

ToolPocket · ファイルは端末から出ません。送信も登録も、追跡もありません。
