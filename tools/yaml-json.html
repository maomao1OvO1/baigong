FAQ

Why no anchors or multi-document support?

They're rare in configs but multiply parser complexity. A clear error beats a half-working conversion that silently produces something wrong.

Are comments preserved?

No — JSON has no comments, so they're dropped. If you need them, merge the yaml by hand afterwards.
