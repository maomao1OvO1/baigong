FAQ

Why is the usable count 2 less than the total?

In a normal subnet the first address is the network ID and the last is the broadcast, so neither can be assigned to a host. The exception is /31 and /32 (RFC 3021), where this tool reports the real usable count instead of a negative number.

Why do the binary values look odd for 255.255.255.255?

JavaScript bitwise operators work on 32-bit **signed** integers, so that value becomes −1. This tool converts to unsigned before printing — otherwise masks come out as negative numbers.
