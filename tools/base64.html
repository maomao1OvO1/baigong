FAQ

Why does my Chinese/Japanese text turn into garbage elsewhere?

Because those tools call btoa directly, which only understands Latin-1. This page encodes to UTF-8 bytes first, then to Base64 — the correct way.

Can I decode a Base64 string from an email or API?

Yes, and if it isn't valid Base64 you get a clear error instead of silent nonsense.
