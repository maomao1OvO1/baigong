FAQ

Does a successfully decoded token mean it is valid?

No. Anyone can craft a token with any payload; only the signature proves the issuer. This page decodes the format and reads the claims — validate signatures on your server, never in a browser tool.

Why is my token rejected as malformed?

A JWT has exactly three dot-separated parts. Copy-paste often drops the last segment, or a JSON string arrives with quotes and escapes still on it. Also make sure it is not URL-encoded.

Is it safe to paste a production token here?

Nothing is uploaded — but treat tokens like passwords. Prefer a test token; if you must use a real one, revoke or rotate it afterwards.
