FAQ

Why did my colour value survive but the comment after it disappear?

Because a trailing comment only counts when whitespace comes before the ; or #. Without that rule, a value like #fff or a tag like value#1 would lose its tail — the parser cannot know which one you meant, so the rule has to be positional.

What happens if the same key appears twice?

The values are merged into an array instead of the later one overwriting the earlier. Real files do this on purpose (an allow-list, several mounts), and silently dropping a value is much harder to debug than seeing an array.

Why are numbers kept as text by default?

Because config files are full of values where that conversion loses information: 0755 becomes 493, a long ID loses precision, 1.10 becomes 1.1. Flip the switch when you do want numbers and booleans typed, and keep it off when the exact text matters.
