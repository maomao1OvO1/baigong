Bank card / ID validator

A single mistyped digit is the most common input error, and check digits exist to catch exactly that. Bank cards use Luhn, Chinese ID numbers use the GB 11643 check digit — both verified here, on your device. A pass means the format is valid; it does not prove the card or number exists.

FAQ

Is my number uploaded?

No. These numbers are personal data, and this site is built so that nothing you type ever leaves the page — that is a design decision, not a setting.

Can it tell me which bank or region?

Deliberately not. Region lookup needs an external database, which would mean sending your number somewhere. It only does the check-digit arithmetic.
