FAQ

I submitted my sitemap but Search Console says the URLs are outside my property — why?

Almost always a domain mismatch: the sitemap lists https://username.github.io/... while the property you verified is https://yourdomain.com. Search engines compare hostnames literally, so the whole file is rejected. Regenerate the list with the exact domain you verified.

My URL has a query string with & in it. Is that a problem?

Only if you paste the raw URL without escaping. In XML, & must be written as &amp;, otherwise the file is not well-formed and readers stop at the first error. This tool escapes every URL for you.

Do changefreq and priority still matter?

Barely. Google has said it ignores priority entirely, and changefreq is only a hint that is widely ignored too. Use them if another engine you care about reads them; what actually helps is accurate lastmod dates and getting the URLs right.
