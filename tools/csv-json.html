FAQ

Why not just split on commas?

Because real CSV contains commas inside quoted fields, line breaks inside cells (Excel notes columns) and doubled quotes for escaping. A character-by-character parser is the only correct way.

Numbers and true/false — are they converted?

Yes, values that look like numbers or booleans become JSON numbers/booleans, so downstream code does not have to parse strings again. Text like 007 stays a string.

My JSON is nested — what happens?

Each top-level array item becomes a row. Keys are the union of all objects, and nested objects are stored as JSON text inside the cell.
