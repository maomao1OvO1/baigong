FAQ

What is the difference between [a.b] and a.b = 1?

Nothing — both put the key under a table named a. The dotted form is just shorter, and mixing the two in one file is a classic way to end up with two different tables that were meant to be the same one. Seeing the result as JSON makes that visible immediately.

Why is a date kept as text instead of becoming a number?

Because JSON has no date type. Turning 2026-10-14T09:30:00Z into a timestamp would silently drop the offset and change how it reads. Keeping the original text loses nothing; a wrong conversion is hard to spot.

Does it handle multi-line strings and comments?

Yes — triple-quoted strings (both """ and ''') keep their line breaks, and # comments are ignored including inside arrays. Note that a # inside a quoted string is content, not a comment, which is where a regular-expression approach usually breaks.
