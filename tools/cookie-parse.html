FAQ

Which attribute actually matters most?

HttpOnly for session cookies. Without it every script on the page can read the value, so a single XSS is enough to walk away with the session. Secure comes next: it keeps the cookie off plain HTTP requests. SameSite is the one people forget — and SameSite=None without Secure means the browser discards the cookie outright, which is the classic "it works on localhost, not cross-site" bug.

Are there limits on how big a cookie can be?

Yes, roughly 4 KB per cookie including the name and attributes, and browsers also cap how many cookies a single domain may set (often around 180). Anything larger is silently dropped — and because it is silent, the failure looks like a random logout rather than an error.

Does this tool validate or use the cookie?

No. It only parses the text you paste, and nothing is sent or requested — a cookie is a session credential, so it should never be handed to an online service for decoding.
