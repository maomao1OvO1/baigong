String escape / unescape

The same string has six different correct spellings depending on where it goes. JSON cannot contain a raw newline or an unescaped quote; SQL needs single quotes doubled, not backslashed; a regex needs a pile of characters backslashed. This does it in one shot — and can turn any of them back into readable text.

FAQ

Does escaping make my SQL safe?

No. This is for writing string literals correctly; it is not injection protection. Use parameterised queries for that — the tool's own hint says the same thing.

Which direction do I need?

Pick the target format and whether you are escaping or unescaping. The swap button flips both the text and the direction, so you can round-trip to check.
