FAQ

What exactly gets removed?

Comments (that is where editor metadata usually lives) and whitespace that sits between tags. Whitespace inside tag attributes collapses to a single space. Text nodes and CDATA sections are copied through character for character.

Could compressing break my drawing?

Not through whitespace: in SVG, whitespace between elements is not significant, unlike inside a element or an element marked xml:space="preserve" — and those two are exactly what this tool leaves alone.

Does it optimise the paths like svgo?

No. There is no path rewriting, no group removal, no precision reduction. Those need a geometry-aware tool and can change the rendering; this does the one thing that is provably safe.
