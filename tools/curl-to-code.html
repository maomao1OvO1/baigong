FAQ

It says the body lives in a file — why can't you convert that?

Because the command is `-d @data.json`: the body is read from a file at run time, and that file is not part of the command. Rather than invent an empty body and let you debug a request that never had a chance, the tool stops and tells you to inline the data.

Where did -L, -k and --compressed go?

They are curl behaviours with no useful equivalent, so they are dropped on purpose: fetch and axios follow redirects already, both decompress automatically, and `-k` (skip certificate checks) is something you should never carry into production code.

Can it go the other way, from code to curl?

No. One code snippet maps to many curl commands, so the reverse has no single correct answer. Going curl → code is unambiguous, which is why this tool does only that.
