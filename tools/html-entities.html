FAQ

Do I need to escape quotes too?

Inside an HTML text node, only & and < are strictly required. Inside an attribute value (in double quotes), escape " as well. This tool escapes the five common characters, which is always safe.

Should I convert Chinese into entities?

Only if something downstream demands pure ASCII. Otherwise it triples the file size and makes the source unreadable. That is why it is a separate switch, off by default.
