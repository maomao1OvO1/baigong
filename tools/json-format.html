FAQ

What does it do with invalid JSON?

It tells you the error and tries to point at the line and column, so you can fix it instead of guessing.

Is there a size limit?

No hard limit — it runs on your machine, so it handles large pastes as fast as your device does.

Does it send my data anywhere?

No. Useful if the JSON contains API keys or customer data.
