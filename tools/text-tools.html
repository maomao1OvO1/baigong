FAQ

Why are these on one page instead of seven?

Because each alone is too small to remember the URL of. One page, one bookmark, and every option is one click away.

Does it handle Chinese/Japanese text?

Yes. Case conversion is a no-op for CJK (there is no case), but counting, trimming, deduplicating and sorting all work — sorting uses locale-aware order.

Is my text uploaded?

No. Nothing leaves this page.
