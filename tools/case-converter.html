FAQ

Which style should I use in code?

Follow the language's convention: camelCase for JavaScript/Java variables, snake_case for Python/Rust, PascalCase for types and classes, CONSTANT_CASE for module-level constants. Consistency inside one file matters more than which one you pick.

What about Chinese or Japanese text?

CJK characters have no case, so they pass through unchanged. That is expected: camelCase is a convention for Latin-script identifiers and gives no benefit to CJK.

Does it handle multiple lines?

Yes. Each non-empty line is converted independently, which makes it handy for turning a pasted list of column names into one style.
