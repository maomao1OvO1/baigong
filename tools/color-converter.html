FAQ

Which formats does it accept?

#abc, #aabbcc, rgb(r,g,b), rgba(...) and hsl(h,s%,l%) — with or without spaces.

Is it exact?

RGB ↔ HEX is exact. HSL is rounded for readability but the underlying conversion is standard CSS math.

Why not a color picker?

There is one below the input — but most people arrive with a color already copied, so pasting is the fast path.
