FAQ

Why is my apostrophe breaking the statement?

Because a single quote inside a SQL string literal has to be written twice: O'Brien becomes 'O''Brien'. It is the single most common way hand-built INSERT statements fail, and the failure looks like a syntax error far from the real cause. This tool escapes every value.

Empty cells — NULL or empty string?

NULL by default, because the two mean different things in a database and guessing wrong is hard to notice after the import. There is a switch if you need empty strings instead; it applies to cells that are empty or whitespace-only.

How are column types decided?

Conservatively. A column becomes INTEGER only if every value is an integer, REAL if every value is numeric, and TEXT otherwise. CSV carries no type information, and values like 0755 or 1.10 lose information when treated as numbers — so anything uncertain stays text.
