FAQ

Where do the optional (?) fields come from?

From your data. When an array holds several objects and a key is missing from some of them, that key is marked optional — which is what the real API does. Untick the option to make every field required instead.

What happens when one field is a string in one element and a number in another?

You get a union: string | number. That is deliberate — collapsing it to any would just move the error to wherever you use the type.

Why unknown[] for an empty array?

An empty array carries no information about its elements, so there is nothing honest to infer. unknown[] forces you to say what goes in it, while any[] silently lets anything through.
