FAQ

Which one do I need for ZIP or PNG?

CRC-32 — the IEEE 802.3 polynomial 0xEDB88320. Adler-32 is the zlib one, and it is faster but weaker: it misses some byte swaps that CRC-32 catches.

Can I use these to prove a file was not tampered with?

No. They are designed to catch accidental corruption — a flipped bit from a bad cable or a failing disk — and an attacker can trivially craft different content with the same checksum. For integrity against tampering you need a cryptographic hash such as SHA-256, or better a signature.

Why did the hex mode reject my input?

It takes an even number of hex characters, optionally separated by spaces, colons, commas or dashes, with an optional 0x prefix. An odd count means the string is not a whole number of bytes — guessing at a missing digit would produce a confidently wrong checksum, which is worse than refusing.
