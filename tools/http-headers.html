FAQ

The page still shows an old version — which header do I look at?

Cache-Control first, then Age and ETag. max-age says how many seconds the copy stays fresh, no-cache means revalidate before every use, no-store means never write it to disk, and a large Age means you are reading something the CDN cached a while ago. immutable tells the browser not to revalidate at all for the whole max-age window, which is what versioned asset URLs rely on.

Why are security headers worth checking?

Because a missing one throws no error and logs nothing — you just quietly have one layer less. A cookie without HttpOnly can be read by any script on the page (including one injected by XSS); a site without Strict-Transport-Security stays downgradable to plain HTTP on the first visit.

It says a header has no explanation — is that a bug?

No. This tool explains a curated set of common headers and lists anything else as-is. Inventing a plausible-sounding meaning for a header it does not know would be worse than admitting it does not know.
