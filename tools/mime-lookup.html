FAQ

My CSS loads but is not applied — could MIME be the reason?

Very likely. A stylesheet served as text/plain is refused outright by the browser: it will not apply the rules and the console says MIME type mismatch. The same applies to JavaScript served as text/plain. It is the most common cause of "the file is there but nothing happens" on a static site.

One MIME type has several extensions — does it matter which I use?

Not to the server, which only sees the type. It matters for humans and tooling: .jpeg and .jpg are the same image, .mjs exists mainly to tell Node that a file is an ES module.

Is it safe to validate an upload by extension or MIME type?

No. Both are supplied by the client and can be changed with a text editor. Send a PHP file named photo.png with image/png and an extension-only check waves it through. The server has to sniff the actual bytes and, ideally, re-encode the file before storing it.
