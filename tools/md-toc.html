FAQ

Why does my link do nothing when I click it?

Almost always one of three things: the anchor keeps punctuation that GitHub strips, capital letters that GitHub lowercases, or it collides with an earlier identical heading — GitHub then points the second one at name-1. This tool follows GitHub's rules on all three.

Do Chinese, Japanese and Korean headings work?

Yes. GitHub keeps CJK characters in the anchor exactly as written and only lowercases and strips punctuation, so the anchor is the heading text itself. That is also why this tool never transliterates a heading.

Will the same Markdown work on GitLab or Notion?

Not always — each platform has its own anchor rules, and GitLab in particular differs. This tool follows GitHub, which is the most common target. If a link fails elsewhere, that is the other platform's rule, not a bug here.
