FAQ

Will blocking AI crawlers also block normal search traffic?

No — the generated section lists specific tokens only; Googlebot and Bingbot are never included, so ordinary search indexing is unaffected. One caveat: ChatGPT-User fires when a user explicitly asks it to open your page, so blocking it also blocks that live visit.

Does robots.txt actually stop a crawler?

It is a request, not a wall. Well-behaved crawlers obey it; scrapers that ignore it will still fetch your pages. If you need to actually block something, do it at the edge — a firewall or WAF rule.

Why not just write "/sitemap.xml" on the Sitemap line?

Because that line takes an absolute URL only. A relative path is silently invalid — engines simply ignore it, and you usually have no way to tell that it was dropped.
