FAQ

Does key order matter?

No — and that is the point. JSON objects are unordered by definition, so reformatting or reordering them produces no differences here, while a text diff would report the whole document as changed.

How are arrays compared?

By index, because arrays are ordered in JSON — [1,2] and [2,1] are genuinely different values. A shorter array shows up as removed indices, a longer one as added indices. For a large array, that is a hint that you may actually want a set comparison instead.

How is this different from the other diff tools here?

The line-by-line and character-level tools compare text and are the right choice for prose, config files and logs. This one compares meaning: it needs valid JSON on both sides, and in exchange it tells you exactly which path changed and by how much.
