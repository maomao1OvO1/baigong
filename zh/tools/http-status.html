常见问题

4xx 和 5xx 到底怎么分？

4xx 是「你发的东西有问题」（参数错了、没登录、太频繁），5xx 是「我这边的机器有问题」（崩了、过载、上游超时）。改代码还是扩容，就靠这条线分。

为什么 418、499、599 标了非官方？

它们不在 RFC 里：418 是愚人节玩笑、499 是 Nginx 自造的、599 常见于代理。标出来免得你以为自己记错了。
