常见问题

它会改我字符串里的内容吗？

不会，这正是「先扫描」的意义。像 name = 'select * from users' 这种条件，里面的文字是**数据**不是 SQL —— 直接做关键字替换会改掉存进去的值，等于偷偷改变查询行为。本工具先切 token 分类，再决定动不动。

它支持哪些数据库方言？

它压根不按方言解析，而是按 token 类型排版 —— 所以 PostgreSQL、MySQL、SQLite、SQL Server、BigQuery 都能用。代价是：真正的语法错误它也不会指出来。`--` 与 `#` 行注释、块注释、`''` 转义、反引号与方括号引号都认。

为什么不把我的表名字段名也一起大写？

因为那会改变它们。PostgreSQL 里未加引号的标识符会被折叠成小写，大小写敏感的排序规则下改大小写等于换了一张表。这里只动关键字，标识符一律照原样保留。
