JSON 格式化与校验

粘进来一团乱码级的 JSON，还你一份能读的。要是坏的，它会告诉你坏在哪，而不是甩一句“unexpected token”。

完全在你的浏览器里运行，不上传、不保存。

「格式化」加缩进方便阅读；「压缩成一行」去掉所有空白，方便传输。

常见问题

遇到非法 JSON 会怎样？

显示错误信息，并尽量指出出错的行列号，让你能直接改，而不是猜。

有大小限制吗？

没有硬限制 —— 跑在你自己的设备上，你的机器多快就有多快。

数据会被传走吗？

不会。如果 JSON 里含 API key 或客户数据，这点尤其重要。
