常见问题

遇到非法 JSON 会怎样？

显示错误信息，并尽量指出出错的行列号，让你能直接改，而不是猜。

有大小限制吗？

没有硬限制 —— 跑在你自己的设备上，你的机器多快就有多快。

数据会被传走吗？

不会。如果 JSON 里含 API key 或客户数据，这点尤其重要。
