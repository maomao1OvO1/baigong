常见问题

支持哪些关键字？

`type`（含数组形式）、`required`、`properties`、`items`、`enum`、`minimum`、`maximum`、`minLength`、`maxLength`、`pattern`、`minItems`、`maxItems`，以及 `additionalProperties: false`。这覆盖了实际校验的绝大多数场景。**不解析 `$ref`**，也**不做 `format` 的语义检查**（如 email、date-time 的格式）。

schema 里用了 $ref 会怎样？

工具会在结果里**明确写出来这段没校验**，而不是悄悄放过。一个「看不懂的规则就跳过」的校验器比没有校验器更糟 —— 你会以为数据没问题，其实什么都没检查。

为什么错误信息要带上路径？

因为在嵌套数组的文档里，只说「类型不对」根本不知道去哪儿找。像 `data.items[2].price` 这样的路径，能把五分钟的翻找变成一行的修改。
