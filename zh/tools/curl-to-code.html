常见问题

它说 body 在文件里，为什么转不了？

因为那条命令写的是 `-d @data.json`：body 是运行时从文件读的，而文件不在命令里。与其编一个空 body 让你去调一个根本没机会成功的请求，不如直接告诉你把数据内联进来。

-L、-k、--compressed 这些去哪了？

它们属于 curl 自身的行为，没有对应的代码写法，是故意去掉的：fetch 和 axios 本来就会跟随重定向、本来就会自动解压；而 `-k`（跳过证书校验）这种东西，绝不该被带进正式代码里。

能不能反过来，把代码转成 curl？

不能。一段代码能对应很多条 curl 命令，反过来没有唯一正确答案；而 curl → 代码是确定的，所以这个工具只做这一个方向。
