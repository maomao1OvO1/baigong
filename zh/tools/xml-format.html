本工具只在「元素内容全是子元素」的地方换行，遇到不能动的地方会在状态行里告诉你。

常见问题

为什么我的一段 XML 没有被拆开，还是一长行？

因为那个元素是**混合内容** —— 文字与子元素混在一起，像 `

你好 世界

`。在这种地方插入换行等于给文本加了空白，而空白在 XML 里是真实数据。本工具整体不动它，并在状态行里说明，而不是偷偷改掉。

压缩模式到底删了什么？

只删**标签之间**的空白 —— 那里只可能是缩进。文本节点里的空白原样保留，所以压缩前后文档内容完全一致，差别只是没有了排版。

XML 写错（标签没闭合）它会告诉我吗？

不会，这是有意的。它是文本级工具：不检查标签配对、不做 DTD 校验；没闭合的标签会原样带过去，而不是替你猜一个闭合位置。要校验请用真正的解析器。
