常见问题

为什么我的表格在编辑器里看着对齐，渲染出来是歪的？

因为源码是按字符数补空格的，而渲染看的是显示宽度。中文、全角标点、emoji 都占两格却只算一个字符 —— 按字符数对齐的结果就是「源码整齐、渲染错位」。本工具数的是真实显示宽度。

有个格子里含竖线，结果被拆成两列了。

Markdown 里格子内的竖线必须写成 `\|`，本工具认这个转义并会保留它。如果粘进来的内容本来就没转义，那解析器无法区分「分隔符」和「内容」—— 换成任何工具都一样，因为这个信息在文本里根本不存在。

对齐方式有哪些？

左、居中、右三种，写成 `:---`、`:---:`、`---:` 这几种大多数 Markdown 方言都认的形式。居中是通过补空格实现的，不去改分隔符，所以在忽略对齐的渲染器里也不会出错。
