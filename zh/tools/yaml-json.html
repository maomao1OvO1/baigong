常见问题

为什么不支持锚点和多文档？

那两类语法在配置里占比很小，却会让解析器复杂好几倍。与其半吊子支持、结果错得看不出来，不如明确报错。

注释会保留吗？

不会 —— JSON 本身没有注释，转换过程里注释会丢掉。想保留的话，改完 yaml 再手工合回来。
