字符串转义 / 反转义

同一个字符串，放进不同的地方有不同的正确写法：JSON 里不能有裸换行、也不能有没转义的双引号；SQL 里单引号要写成两个而不是加反斜杠；正则里一堆符号都得加反斜杠。这里一次转对，也能把任何一种解回原文。

常见问题

转义之后我的 SQL 就安全了吗？

不是。这只解决「字面量怎么写才对」，不等于防注入 —— 防注入要用参数化查询。页面提示里也写了同一句话。

该选哪个方向？

选目标格式，再选是转义还是反转义。「互换」按钮会把文字和方向一起翻过来，方便做一次往返校验。
