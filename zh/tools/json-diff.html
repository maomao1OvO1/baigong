常见问题

键的顺序会影响结果吗？

不会 —— 这正是重点。JSON 对象按定义是无序的，所以重新格式化或调整键序在这里不会产生任何差异，而文本对比会把整份文档报成「全变了」。

数组是怎么比的？

按下标比，因为 JSON 里数组是有序的 —— `[1,2]` 与 `[2,1]` 确实是不同的值。短了会显示为被删除的下标，长了显示为新增的下标。如果一个大数组全是差异，通常说明你其实想做的是集合比较。

它和站里其他对比工具有什么区别？

逐行对比与字符级对比比的是**文本**，适合文章、配置文件和日志。这个比的是**结构**：两边都必须是合法 JSON，换来的是「到底哪个路径变了、改成了什么」这个精确答案。
