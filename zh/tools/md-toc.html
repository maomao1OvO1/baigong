常见问题

为什么我的目录点下去没反应？

九成是三种情况之一：锚点里留了 GitHub 会去掉的标点、留了会被转成小写的大写字母、或者和前面某个同名标题撞了 —— 撞名时 GitHub 会把第二个指向 name-1。这三条本工具都按 GitHub 的规则处理。

中文标题能用吗？

能。GitHub 的锚点对中日韩文字是原样保留，只做小写和去标点，所以「中文标题」的锚点就是 #中文标题。这也是本工具不把标题音译或转写的原因。

同一份 Markdown 在 GitLab 或 Notion 上也能用吗？

不一定 —— 各家锚点规则不一样，GitLab 差别尤其明显。本工具按 GitHub 走，那是最常见的去处。在别处点不动，是那家的规则问题，不是这里算错了。
