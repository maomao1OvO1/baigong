常见问题

代码里该用哪种风格？

跟着语言约定走：JavaScript / Java 的变量用 camelCase，Python / Rust 用 snake_case，类型与类名用 PascalCase，模块级常量用 CONSTANT_CASE。同一个文件里保持一致，比选哪一种更重要。

中文、日文会怎么样？

中日文没有大小写，会原样保留 —— 这是正常的：驼峰是拉丁字母命名的约定，对中日文不产生变化。

支持多行吗？

支持。每个非空行单独转换，所以把一列字段名贴进来统一改风格很方便。
