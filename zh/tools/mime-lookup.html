常见问题

我的 CSS 加载了却不生效，会是 MIME 的问题吗？

很可能就是。样式表被以 text/plain 返回时，浏览器会**直接拒绝**应用它，控制台只说一句 MIME type mismatch。JavaScript 同理。这是静态站「文件明明在、就是没反应」最常见的原因。

一个 MIME 对应好几个扩展名，用哪个有区别吗？

对服务端没区别（它只看类型），对人和其他工具才有：.jpeg 与 .jpg 是同一张图，而 .mjs 存在的意义主要是告诉 Node「这是 ES 模块」。

用扩展名或 MIME 做上传校验安全吗？

不安全。两者都是客户端给的，改个名字就能绕过：把一个脚本文件命名成 photo.png、类型写 image/png，只查扩展名的校验就放行了。服务端必须嗅探真实字节（magic bytes），最好再把文件重新编码一次存下来。
