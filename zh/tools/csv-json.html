常见问题

为什么不能直接用逗号切分？

因为真实的 CSV 里有三种情况会出错：引号包着的字段本身带逗号、单元格里有换行（Excel 导出的备注列常见）、引号用两个双引号转义。只有逐字符扫描才能处理对。

数字和 true/false 会被转换吗？

会。看起来像数字或布尔值的字段会变成 JSON 里的数字 / 布尔，省得下游再解析一遍字符串；但像 007 这种会被当作文本保留。

JSON 是嵌套结构怎么办？

顶层数组的每一项对应一行；键取所有对象的并集；嵌套的对象会以 JSON 文本的形式放进单元格。
