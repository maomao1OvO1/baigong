常见问题

能解开是不是就说明 token 合法？

不是。任何人都能造出一个载荷任意的 token，只有签名才能证明签发者。本页只做格式解码与声明解读；签名校验请放在你的服务端，绝不要交给浏览器里的工具。

为什么提示我的 token 格式不对？

JWT 必须是点号分隔的三段。复制粘贴时最常见的是漏掉最后一段，或者粘进来的是带引号和转义的 JSON 字符串；另外确认它没有被 URL 编码过。

生产环境的 token 贴这里安全吗？

本页不上传任何内容，但 token 等于密码。建议用测试 token；如果非要用真的，用完记得吊销或轮换。
