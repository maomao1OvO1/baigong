常见问题

为什么我的单引号会让语句报错？

因为 SQL 字符串字面量里的单引号要写成两个：O'Brien 得写成 'O''Brien'。这是手拼 INSERT 最常见的失败方式，而且报的错往往离真正的原因很远。本工具会把每个值都转义。

空单元格写成 NULL 还是空字符串？

默认 NULL，因为这两者在数据库里含义不同，猜错了导入之后很难发现。需要空字符串就把那个开关关掉；它只作用于「空的或只有空白」的单元格。

列的类型是怎么定的？

保守地定。整列都是整数才给 INTEGER，都是数字给 REAL，其余一律 TEXT。CSV 本身不带类型信息，而 `0755`、`1.10` 这类值当数字处理会丢信息 —— 所以拿不准的一律留文本。
