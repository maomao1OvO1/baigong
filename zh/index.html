    🖼️图片2

    • 🗜️ 压缩图片，不用把它传给别人 把照片压小，不用先传到别人服务器上。图片在你浏览器里解码、缩放、重新编码，手机拍的原图常常能压到原来的几分之一 —— 原图始终留在你手机里。
    • 🔄 换图片格式，不用先上传 HEIC、PNG、JPEG、WebP 互相转换，不用上传。专治两种常见情况：手机拍的照片在电脑上打不开、某个网站只收 JPEG。

    ✍️文本与数据8

    • 🧷 HTML 实体编码 / 解码 把 HTML 转义成页面上能安全显示的文字，或者把一串 中 还原回来。给邮件模板、只吃 ASCII 的老系统输出内容时也用得上。
    • 🆚 文本对比（逐行） 两段文本逐行对比，看清到底哪里变了 —— 连看不见的差异也揪得出来：行尾多一个空格、换行符是 Windows 的。这种「看着一样、其实不一样」最容易误事。
    • 🔤 命名风格转换 命名风格互转：camelCase、PascalCase、snake_case、kebab-case、CONSTANT_CASE。缩写按人的习惯拆 —— HTTPServer 会变成 h…
    • 📊 CSV ⇄ JSON 互转 CSV 与 JSON 互转，专治把简单工具搞崩的三种情况：引号里的逗号、单元格里的换行、两个引号转义成一个。Excel 导出的表格里，往往三种都有。
    • 🔠 Base64 编码 / 解码 Base64 编码解码，中文和 emoji 不会变成「？？？」。很多在线工具直接调浏览器的原始接口，非英文内容一进去就乱码；这里是先按 UTF-8 转好再编码，所以不会。
    • 🧩 JSON 格式化与校验 JSON 美化、压缩、校验；格式错了会告诉你具体哪一行。贴接口返回的数据时最省事 —— 而这恰好是最不该发给陌生网站的那类内容。
    • ✍️ 日常文本处理，一个页面搞定 零碎的文本活：大小写转换、反转、去空行、去重、排序、统计字数。即时出结果，也不用把内容贴进一个满屏广告的页面。
    • 🔗 URL 编码 / 解码 URL 和查询串的百分号编解码。特意把「整个网址编码」和「只编码一个参数值」分开 —— 回调地址接不上，九成是这两种混着用了。

    ⌨️开发者8

    • 🔗 URL 拆解 / 查询参数查看 把长链接拆开，查询参数一条一行。所谓「这链接怎么不对」，九成坏在查询串：少一个 &、值被编码了两遍，或者 # 把整个查询串吃掉了。
    • 🌐 IPv4 / CIDR 子网计算 输入 192.168.1.10/24 这样的地址，算出网络地址、广播地址、可用主机范围、掩码与反掩码，并直接告诉你它是私有、回环还是公网地址。
    • ⏰ Cron 表达式解析 贴一条 cron 表达式，逐段翻译成人话，并按你的时区算出接下来 5 次运行时间。省得盯着 5 个星号猜半天，最后才发现是某一格写错了。
    • 🔐 哈希计算（MD5 / SHA-1 / SHA-256 / SHA-512） MD5、SHA-1、SHA-256、SHA-512 一次算完，同时给 hex 和 Base64。浏览器早就不提供 MD5 了，这里是手写的实现 —— 算个校验值，不该还要把内容发出去。
    • 🧪 正则表达式测试器 用你自己的文本试正则：每一处匹配的行号、位置、捕获组都列出来。日志这类文本尤其适合在这里试 —— 里面常有客户信息，不适合贴到别人的网站上。
    • 🆔 UUID / ULID / NanoID 生成器 生成 UUID v4、可按时间排序的 v7、ULID、NanoID，一次最多 100 个。随机源是浏览器的加密级随机数，不是 Math.random。
    • 🔢 进制转换（2 / 8 / 10 / 16 / 36） 二进制、八进制、十进制、十六进制、36 进制互转，还给一个分组位视图，用来看标志位和掩码。长数字走 BigInt —— 18 位的 ID 不会被悄悄改掉末几位。
    • 🎫 JWT 解析器 看清 JWT 的头部、载荷和过期时间，不用把它贴进别人的分析后台。解码就在这一页完成 —— 另外记住：能解开不等于合法，签名要在你自己的服务端验。

    🎨颜色2

    • 🎨 配色板生成 从一个颜色出发，拿到整套搭配：互补色、类似色、三角色，外加同色相的 7 档明度。hover、按下、禁用这几种状态照它来定，就不会越调越脏。
    • 🎨 颜色转换 —— HEX / RGB / HSL 颜色在 HEX、RGB、HSL 之间互转，一次把三种写法都摆出来 —— 把设计稿里的 HSL 值落到 CSS 时，这样最省事。

    🕒时间与单位3

    • 📅 日期计算器 算一个日期离今天多少天、加减 N 天是哪天，并给出星期、年内第几天、ISO 周号。按「日历天」计算，夏令时切换不会让结果变成半天。
    • 📏 单位换算 长度、重量、数据大小、温度一站换算，并把换算系数一并写出来 —— 结果对不对，你自己能核对，不用信一个黑盒。
    • ⏱️ Unix 时间戳转换 Unix 时间戳和日期时间互转，本地时间与 UTC 并排显示。10 位当秒、13 位当毫秒自动判断 —— 这类数字出错，多半就错在这儿。

    🔒安全2

    • 🔑 密码生成器 用浏览器的加密级随机数生成密码，可以排除容易看错的字符（0 和 O、1 和 l）—— 要念给别人听，或者在电视遥控器上输入时，这个选项很救急。
    • 🛡️ 密码强度检测 看清一个密码在暴力猜测下能撑多久，以及它弱在哪：重复字符、键盘连按、生日、手机号。泄露查询必须你手动确认才会联网，而且只发哈希的前 5 位，别的什么都不发。

    那它图什么？

    图的是它真不花钱：没有服务器在替你干活。压图、转格式、格式化 JSON 这些事，你的浏览器本来就会做。那些非让你上传文件的站，是在花钱买机器处理你的文件 —— 所以才有次数限制、水印和「开通会员」的弹窗。这笔成本我们没有，也就没有这些套路：不收账号去卖、不倒腾你的数据、页面里也没有第三方统计脚本。
