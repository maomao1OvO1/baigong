不跟你要邮箱的工具

大多数「免费工具」先跟你要账号，再跟你要文件。这里不要。每个工具都跑在你自己浏览器里，文件根本不经过服务器 —— 不用注册、没有「每小时 3 张」、也不用排队。

🔍

    这里有什么

    • 🧷 HTML 实体编码 / 解码 把 <script> 变成页面上能安全显示的文字，或者把一串 &#x4E2D; 还原回来。需要给邮件模板或老系统输出纯 ASCII 时，这个工具正好用得上。
    • 📅 日期计算器 填一个日期（留空就是今天），立刻得到它离今天多少天、加 N 天之后是哪天，以及星期几、年内第几天、ISO 周号。
    • 🔗 URL 拆解 / 查询参数查看 贴一条长链接，看清它真正的组成部分，查询参数一条一行。「这链接怎么不对」的问题九成出在查询串：少一个 &、值没编码对，或者 # 把整个查询串吃掉了。
    • 🎨 配色板生成 一个颜色进去，一整套搭配色出来：互补、类似、三角，外加同色相的 7 档明度。界面里需要 hover / 按下 / 禁用这几个变体时，按这个改就不会跑色。
    • 🌐 IPv4 / CIDR 子网计算 输入 192.168.1.10/24，直接得到网络地址、广播地址、主机范围、两种掩码和地址总数，并告诉你它是私有、回环还是公网地址。
    • ⏰ Cron 表达式解析 贴一条 */15 9-18 * * 1-5，逐段翻译成人话，并列出未来 5 次运行时间。「任务怎么没跑」几乎都是某一格写错了。
    • 🔐 哈希计算（MD5 / SHA-1 / SHA-256 / SHA-512） 粘一段文字，选一个算法，直接拿到 hex 与 base64 两种结果。整个过程在你设备上完成 —— 校验值往往来自不方便外发的文件，传给服务器是不必要的风险。
    • 🧪 正则表达式测试器 写一条正则，把要匹配的文本贴进来，右边会逐条列出命中的位置、内容与捕获组；填上替换内容还能预览替换结果。日志里常有客户数据 —— 这一页把它们留在你设备上。
    • 🆔 UUID / ULID / NanoID 生成器 挑项目需要的那种，选好数量，整批复制走。随机源用的是 crypto.getRandomValues，不是 Math.random。
    • 🆚 文本对比（逐行） 先贴旧版本，写一行 ===，再贴新版本。结果里每行前面会有标记：- 是删掉的、+ 是新增的、空格是没变的。
    • 🔤 命名风格转换 贴一个名字或一整列名字（每行一个），一次得到所有常见风格。缩写会按人的习惯拆开：HTTPServer 转成 http_server，而不是 h_t_t_p_server。
    • 🔢 进制转换（2 / 8 / 10 / 16 / 36） 输入一个数，同时得到各常见进制的写法，以及它占多少位、多少字节。长数字走的是 BigInt，18 位的雪花 ID 不会被悄悄四舍五入。
    • 🎫 JWT 解析器 贴一个 token，用清晰的 JSON 看清它的头部与载荷，exp、iat、nbf 会翻译成真实时间。解码不是验签 —— 本页从不校验签名。
    • 📊 CSV ⇄ JSON 互转 两种格式都能贴，方向随时切换。引号包裹的字段、字段里的逗号、单元格里的换行都能正确处理 —— 这三种情况正是把 split(",") 写法搞崩的地方。
    • 🗜️ 压缩图片，不用把它传给别人 照片拖进来，就在这儿变小。不用账号、不用上传、没有「升级会员去水印」、也没有每天几张的限制。碰上「文件太大传不上去」的时候正好用。
    • 🔄 换图片格式，不用先上传 除了 HEIC 那种特殊情况，日常的格式麻烦基本就是 PNG ↔ JPG ↔ WebP。拖进来、选输出格式、完事 —— 文件不会离开你的设备。
    • 🔠 Base64 编码 / 解码 中文、日文、emoji 都不会乱码 —— 很多在线工具遇到非英文就出错，因为它们直接用了浏览器的 btoa。这里是先转 UTF-8 再编码，才是正确做法。
    • 🧩 JSON 格式化与校验 粘进来一团乱码级的 JSON，还你一份能读的。要是坏的，它会告诉你坏在哪，而不是甩一句“unexpected token”。
    • 🎨 颜色转换 —— HEX / RGB / HSL 手里有什么就粘什么，自动识别格式，另外两种直接给你 —— 不用先选“输入类型”，少一步就是少一次放弃。
    • ✍️ 日常文本处理，一个页面搞定 以前要开七个网站的小事：大小写转换、文本反序、逐行去空格、删重复行、按行排序、统计字数/词数/行数。现在都在这儿。
    • 📏 单位换算 输一个数，同类别里所有单位一起出来 —— 不用先选“从哪个换到哪个”。支持长度、重量、数据大小、温度。
    • 🔗 URL 编码 / 解码 经典坑：用错函数把整条链接编码了，结果链接直接失效。这里你选要编码什么，工具自动用对的那个函数 —— 不用猜。
    • ⏱️ Unix 时间戳转换 粘一个时间戳或日期，本地时间和 UTC 并排显示，外加 ISO 8601。秒/毫秒自动识别 —— 这正是最容易搞错的地方。
    • 🔑 密码生成器 用的是 crypto.getRandomValues —— 浏览器生成密钥用的同一套系统级随机源，不是可预测的 Math.random。密码不会离开这个页面。
    • 🛡️ 密码强度检测 输一个密码，给你一份真报告：熵估算、命中了哪些弱模式、被暴力破解要多久 —— 全部在你设备上算。泄露查询是可选项，必须你点确认才会联网。
